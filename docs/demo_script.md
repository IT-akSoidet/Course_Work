# Сценарий демонстрации на защите

## Подготовка
1. `docker compose up -d`
2. `python -m pip install -r requirements.txt`
3. `python -m alembic upgrade head`
4. Импорт демо-расписания через команду админа:
   - `/import_schedule data/sample_schedule.csv`

## Сценарий 1: студент
1. Ввести `/rooms 2026-05-15 10:00;2026-05-15 11:30;20`
2. Показать, что аудитории из расписания исключены.
3. Создать бронь:
   - `/book 10102;2026-05-15 10:00;2026-05-15 11:00;Проектная встреча`
4. Проверить `/my_bookings`.

## Сценарий 2: конфликт
1. Отправить вторую заявку на тот же слот.
2. Показать перевод заявки в `pending`.

## Сценарий 3: админ
1. Выполнить `/admin_queue`.
2. Подтвердить заявку `/approve <id>` или отклонить `/reject <id>`.
3. Повторно показать очередь и изменение статуса.

## Сценарий 4: отмена
1. Отменить бронь: `/cancel <booking_id>`.
2. Показать, что запись больше не активна.
